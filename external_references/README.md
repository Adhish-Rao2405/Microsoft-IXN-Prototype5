# External References

This directory contains read-only reference snapshots used to document future
Prototype 5 extension paths. Files here are not imported by Prototype 5 source
code, scripts, tests, or runtime logic.

## fl-nemotron

`fl-nemotron/` is a minimal reference snapshot of Lee Stott's `fl-nemotron`
project:

https://github.com/leestott/fl-nemotron

It is included only to support the Phase 2 future voice-extension argument:
Foundry Local SDK 1.1.x with NVIDIA Nemotron Speech Streaming is the appropriate
Microsoft-aligned local STT route to investigate next, rather than forcing the
unsupported Whisper HTTP transcription endpoint tested in M15A.2.

Prototype 5 remains a local-first zero-trust robot-task-plan validation system.
The language model proposes; deterministic validation decides.
