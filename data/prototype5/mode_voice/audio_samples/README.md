# M14B Audio Samples

This folder is reserved for future local spoken-command audio artefacts linked by `data/prototype5/mode_voice/audio_manifest.csv`.

M14B intentionally commits no binary audio files. Recordings should remain local and untracked unless a later milestone explicitly approves tiny committed samples.

Recommended recording constraints:

- one command per file
- quiet room
- one speaker
- normal speaking volume
- no background music
- no overlapping speech
- WAV format when possible
- stable lowercase snake_case filenames matching the manifest
- self-recorded audio or explicit consent only

Future STT evaluation should compare automatic transcript output against `data/prototype5/mode_voice/audio_transcript_manifest.csv` without changing the zero-trust validation pathway.
